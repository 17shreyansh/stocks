# 🚀 Start Backend & Frontend Servers

## Quick Start Commands

### 1. Start Backend (Terminal 1)
```bash
cd "d:\Office\Stock Broker\v4\be"
npm run dev
```

### 2. Start Frontend (Terminal 2)  
```bash
cd "d:\Office\Stock Broker\v4\fe"
```
